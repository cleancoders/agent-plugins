# External resources

- **WAI: Introduction to Web Accessibility** — https://www.w3.org/WAI/fundamentals/accessibility-intro/
  Use it for: onboarding context — what web accessibility is, who it affects, and why it matters, before diving into specific criteria.

- **W3C WCAG 2.2 Quick Reference** — https://www.w3.org/WAI/WCAG22/quickref/
  Use it for: looking up the authoritative wording, intent, and techniques for any success criterion by number (e.g. 1.4.3, 2.5.8).

- **ARIA Authoring Practices Guide (APG)** — https://www.w3.org/WAI/ARIA/apg/
  Use it for: correct roles, states, and keyboard interaction patterns when building custom widgets (menus, tabs, dialogs, comboboxes, etc.).

- **WebAIM Contrast Checker** — https://webaim.org/resources/contrastchecker/
  Use it for: verifying text and UI-component color contrast ratios against 1.4.3 and 1.4.11 thresholds.

- **WebAIM WAVE** — https://wave.webaim.org/
  Use it for: a quick automated + visual scan of a live page for common issues (missing alt text, heading structure, contrast, ARIA errors).
